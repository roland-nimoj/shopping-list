# Список покупок

Интерактивная CLI-программа на Python для ведения списка покупок. Список хранится в `shopping_list.json` рядом с `main.py` и сохраняется между запусками.

## Запуск

```bash
python3 main.py
```

В меню доступны действия:

1. Добавить товар.
2. Показать список с номерами и отметками купленных товаров.
3. Отметить товар как купленный по номеру.
4. Очистить список после подтверждения словом `да`.
0. Выйти.

## Тесты

```bash
python3 -m unittest discover -s tests
```
